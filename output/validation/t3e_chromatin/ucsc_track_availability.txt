================================================================================
RECOMMENDATION FOR CellWarp T3-E CHROMATIN THREAD
================================================================================

For scoring evolutionary conservation of regulatory elements near genes in
human-mouse comparison:

  RECOMMENDED: phastCons100way
  - Broadest taxonomic scope (100 vertebrates)
  - Includes mouse (mm10) AND many outgroups to calibrate conservation
  - bigWig format enables fast programmatic access via pyBigWig
  - Smaller file (5.5G vs 6.6G)
  - Per-chromosome alternatives available if needed
  - md5sum available for download verification

  AVOID: phastCons20way and phastCons30way for this purpose
  - Both are primate-dominated alignments (17/20 and 26/30 primates)
  - Conservation scores will be inflated for primate-specific elements
  - Less power to detect deep mammalian conservation patterns
  - These are designed for primate-specific analysis, not broad mammalian
    conservation assessment

  ACCESS METHOD: pyBigWig
  - pip install pyBigWig
  - Can query specific genomic intervals without downloading full file
  - Use UCSC remote URL: pyBigWig can open bigWig over HTTP
  - OR download hg38.phastCons100way.bw (5.5G) for faster local queries
