Data Availability

All single-cell RNA-sequencing datasets analyzed in this study are publicly
available. No new data were generated. Fetch instructions, accession numbers,
and required on-disk layouts for the datasets not obtained through CELLxGENE
are documented in DATA_SOURCES.md at the repository root; the summary below
records the canonical accessions for the manuscript.

Deposits:
- Analysis code, the archived Ensembl/BioMart ortholog tables, and the pinned
  dependency manifest: Zenodo, MIT License,
  https://doi.org/10.5281/zenodo.20735612; mirrored at
  https://github.com/sriramdevadas/cellwarp.
- Original analysis outputs: Zenodo, CC0 1.0,
  https://doi.org/10.5281/zenodo.20735640.
- Self-contained basal-ganglia primate-replication deposit, an independent
  reproduction of the Fig 2 two-layer decomposition from the source h5ad with
  the CellWarp method pinned as a versioned dependency: Zenodo, DOI
  [BG_DEPOSIT_DOI - pending mint].

CELLxGENE Census version pinning:
Census-derived data are fetched at Census release "2025-11-08", pinned
explicitly at every cellxgene_census.open_soma() call site under scripts/ and
analysis/; the src/cellwarp/ library receives an already-opened handle and
opens no connection itself. The cellxgene-census client is pinned to v1.17.0
in environment.yml, requirements.txt, and the [lock] extra of pyproject.toml,
which is the extra the documented reproduction path installs; the [reproduce]
extra specifies a >=1.17 floor rather than an exact pin.
tests/test_pan_census_manifest.py::test_census_version_uniform asserts that
the archived pan-Census manifest records "2025-11-08" uniformly; it validates
that manifest, not the version resolved by a fresh run.

Primary atlases:
- Tabula Sapiens (human): CZ CELLxGENE Census (version 2025-11-08); original
  deposit figshare doi:10.6084/m9.figshare.14267219.
- Tabula Muris Senis (mouse): CZ CELLxGENE Census (version 2025-11-08);
  original deposit figshare doi:10.6084/m9.figshare.12654728.
- Tabula Microcebus (mouse lemur): CZ CELLxGENE Discover, downloaded
  2026-04-05. Discover does not version-pin, so the download date is the
  reproducibility anchor; the collection and dataset identifiers are recorded
  in DATA_SOURCES.md and in data/replication/tabula_microcebus_metadata.csv.
- Primate basal ganglia (human, macaque, marmoset; Human and Mammalian Brain
  Atlas consortium): Allen Brain Cell Atlas,
  https://brain-map.org/consortia/hmba.

Replication and comparison datasets:
- Sun et al. (2023): OMIX002605 / GSA CRA007207.
- PanSci (Zhang et al., 2025): GEO GSE247719.
- CellHint Human (Xu et al., 2023): CZ CELLxGENE Census (version 2025-11-08).
- Qu et al. (2022), Macaca fascicularis: GEO GSE196792; author-provided
  cell-type assignments from Zenodo doi:10.5281/zenodo.5881495.
- Andrews et al. (2024): GEO GSE240429.
- Mouse Cell Atlas (Han et al., 2018): GEO GSE108097.
- Pooled human comparison set: CZ CELLxGENE Census query (version 2025-11-08;
  adult, normal, primary Homo sapiens, excluding Tabula Sapiens). The
  15-dataset UUID manifest is archived with the code as
  data/replication/pan_census_manifest.csv.

Reference tables and databases supporting the reported analyses:
- Ensembl BioMart. Human-mouse 1:1 orthologs, release 115, accessed
  2026-03-12; human-macaque orthologs, release 115, accessed 2026-03-15;
  human-mouse lemur 1:1 orthologs by live pybiomart query, release not pinned
  in code (commit-dated 2026-04-05). All three tables are archived in the code
  deposit and are canonical for reproduction, since BioMart returns can shift
  across releases.
- CellMarker 2.0 (http://bio-bigdata.hrbmu.edu.cn/CellMarker/, downloaded
  2026-03-16). The raw database is not redistributed; the derived subset of
  experimentally-validated human marker entries used here is archived in the
  code deposit as data/validation/cellmarker/cellmarker_human_filtered.csv,
  and the filtering criteria are in Materials and Methods. It is an input to
  the conserved-contribution gate reported in Results section 5 (Fig 5).
- MSigDB, supplying the niche-adaptation gene sets and the housekeeping gene
  set: https://www.gsea-msigdb.org/gsea/msigdb/
- STRING v12.0, protein-protein interaction network centrality:
  https://string-db.org/
- DoRothEA (confidence levels A-C), transcription-factor network complexity:
  https://omnipathdb.org. Queried at run time by decoupler (pinned to v2.1.4);
  the query takes no release parameter and retains no local copy, so the
  regulon itself is not version-pinned.
- UCSC Genome Browser: phastCons promoter conservation (placental 20-way
  primary, 100-way vertebrate sensitivity) and refGene TSS annotations for
  hg38 and mm10: https://hgdownload.soe.ucsc.edu/goldenPath/. The refGene
  tables come from a rolling path and no release is recorded.
- ENCODE H3K27ac ChIP-seq for six immune cell types, and Lara-Astiaso et al.
  (2014) mouse bigWig: https://www.encodeproject.org/ and GEO
  GSM1441277-GSM1441283.
- ChEMBL and DrugBank, drug-target conservation (S1 Text, mechanistic null 10,
  an exploratory and non-significant test). The database releases were not
  recorded and the derived tables are not retained, so this input is not
  reconstructible from the deposit; the reported statistic is available as
  output/t3g/primary_correlation_results.json. See DATA_SOURCES.md.

Analyses this paper does not report:
The repository holds analyses and code beyond those reported here; SCOPE.md
records what this paper reports and what it does not. Where an unreported
analysis requires a manual data fetch, its inputs are documented in
DATA_SOURCES.md: DILIrank v2 (FDA NCTR) with LINCS L1000 Phase I Level 2 (GEO
GSE92742); and the Rhesus Immune-Cell Reference Atlas (RIRA), whose
combination with Qu et al. used asymmetric cross-atlas preprocessing and was
deprecated in favour of the single-source Qu design reported here.

SECTION 2 — CODE AVAILABILITY STATEMENT
================================================================

Code Availability

All original analysis code for the CellWarp framework — including data
acquisition, quality control, ortholog mapping, Procrustes superimposition,
permutation testing, bootstrap resampling, leave-one-out cross-validation,
mechanistic null tests, disease deformation analyses, and figure generation —
is archived at Zenodo (https://doi.org/10.5281/zenodo.20735612, MIT License)
and maintained in the project's public GitHub repository
(https://github.com/sriramdevadas/cellwarp). The repository also contains the
archived BioMart ortholog tables and the pre-registration document for the
DILI analysis.
