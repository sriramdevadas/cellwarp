S1 Text. Supplementary Methods.

This document assembles the extended methods and sensitivity analyses that support the main-text findings. Nothing is deleted relative to the analyses on which the paper rests; the lean core Methods carry the primary pipeline, and this text carries the controls, replication inventory, and secondary analyses. Every statistic below traces to a tracked artifact in the deposited code and outputs; the reproduce/validate.py harness checks a subset of them against those files.

1. Independent-PCA sensitivity (artifact-ruling control for the configuration result)

To test whether joint PCA (computing principal components on the combined 70-centroid matrix) manufactures the configuration signal, the analysis was repeated with PCA computed independently on each species' 35 centroids (35 x 16,959 per species), retaining 33 components per species (per-species variance retention 99.96%, since 35 mean-centered centroids span at most 34 dimensions). The two subspaces were aligned by Procrustes on the gene-indexed loading matrices — a pairing-free procedure that uses gene-level orthology, not cell-type labels, which enter only at the permutation test (1,000,000 iterations). The independent-PCA analysis yields obs/null = 0.473 (p < 10⁻⁶), a stronger signal than joint PCA (0.522). This is the opposite of what a joint-PCA artifact would produce: removing the joint embedding should weaken an artifactual signal, not strengthen it. The per-type divergence ranking correlated between the two analyses at Spearman ρ = 0.915 (n = 35); only 2 of 35 types shifted more than 10 ranks and the extremes were stable (CD8+ T cell rank 35 in both). This is an artifact-ruling control, not independent corroboration of the headline. (analysis/independent_pca_sensitivity/)

2. Stratified nulls (lineage and marker-similarity)

Lineage-stratified null. Cell-type labels were permuted only within five lineage blocks (immune/hematopoietic 18 types, epithelial 8, stromal/mesenchymal 7, endothelial 1, metabolic/parenchymal 1; singletons remain matched under all permutations, making the null more conservative). This asks whether per-type positional correspondence is conserved beyond lineage membership. Result: obs/null = 0.668, p < 10⁻⁴ (10,000 iterations); the within-lineage null is 21.9% tighter than the global null and its discriminative power is dominated by the 18-type immune block.

Marker-similarity-stratified null. To test whether the configuration carries information beyond the marker-based matching that defined the landmarks, labels were permuted only within groups of transcriptionally similar cell types (clustering at increasing granularity K). The observed configuration outperforms this finer null through K = 14 and no longer clears p = 0.05 at K = 15 (obs/null 0.52 unrestricted, 0.72 at K = 5, 0.81 at K = 8, 0.90 at K = 10, 0.96 at K = 15; S10 Table, S5 Fig). Part of the rise with K is mechanical: singleton groups are frozen and contribute identically to the observed and permuted statistics, and six of the fifteen groups at K = 15 are singletons. The remainder is a genuine loss of signal rather than an exhausted null, since the nine non-singleton groups at K = 15 still admit about 1.2 billion within-group permutations against the 100,000 drawn. Most of the unrestricted signal is therefore attributable to coarse marker structure, with a residual that persists to K = 14. The per-type residual is independent of marker-distinctness (Spearman ρ = −0.14, p = 0.44). Note that the strata are built from species-averaged centroids of the correctly paired types, so the true correspondence defines the groups within which labels are then permuted. (analysis/sensitivity_analyses/markernull.py)

Parent-and-child landmark sensitivity. The 35 landmarks include Cell Ontology parent labels alongside their own child types (for example monocyte with classical, non-classical and intermediate monocyte; T cell with CD4-positive, CD8-positive and NK T cell; epithelial cell with several of its subtypes). A matched near-duplicate pair contributes a small residual while a shuffled label separates it, so nested labels could contribute disproportionately to a low ratio. Dropping the five parent labels whose children are also present leaves obs/null = 0.521 on the remaining 30 types (p < 10⁻⁴, ranking Spearman 0.936 against the full set); dropping the nine children instead leaves obs/null = 0.544 on 26 types (p < 10⁻⁴, ranking Spearman 0.911). Because both reduced sets have fewer landmarks than the full 35, these ratios are not directly comparable to 0.522; what they establish is that the configuration clears its own null at the permutation floor under either resolution of the nesting.

3. Per-gene normalization schemes (A and B)

The configuration result is robust to per-gene normalization. Under Scheme A (z-scoring each gene across the 35 centroids) and Scheme B (scanpy-style scaling across cells), the configuration stays coherent (obs/null 0.522 -> 0.606 / 0.487) and the per-type ranking is largely preserved (Spearman ρ = 0.54 / 0.76; S9 Table). These schemes are distinct from the ribosomal/housekeeping gene-exclusion check (below). For Layer 2, per-gene standardization (Scheme B) is the biological-axis control: it removes the dominance of a few high-variance genes, and under it the leading conserved within-type axis resolves from ribosomal structure (25/35 ribosomal-dominated types under unscaled weighting) to canonical cell-type markers (1/35 ribosomal; S9 Table). (analysis/sensitivity_analyses/genestd_standardization.py)

4. Ribosomal-protein-gene exclusion sensitivity

To confirm that neither the Layer-1 configuration nor the Layer-2 statistic is carried solely by ribosomal-protein genes, the pipeline was re-run with ribosomal-protein genes excluded. Layer 1: excluding the ribosomal set leaves the configuration essentially unchanged (obs/null 0.522 -> 0.501 with ribosomal-only exclusion; -> 0.479 with an additional MSigDB housekeeping set of 1,158 genes; both p < 10⁻⁴; ranking Spearman ρ = 0.91–0.94; S7 Table). Layer 2: after ribosomal exclusion, pre-rotation S = 0.446 (null 0.329) and post-rotation S = 0.234 (null 0.180), both p < 10⁻⁴, so the covariance statistic persists.

Ribosomal-set definition and a correction. The deposited exclusion uses the strict regex ^(RPL|RPS)\d, which matches 68 genes in the 16,959-ortholog space (analysis/sensitivity_analyses/layer1_exclusion_results.json). This regex undercounts ribosomal-related genes: it misses the acidic stalk proteins RPLP0/RPLP1/RPLP2, RPSA, the RPS30 fusion FAU, the 40S-associated RACK1, the ubiquitin-fusion UBA52, and the 76 mitochondrial ribosomal genes (MRPL*/MRPS*). A corrected cytoplasmic-plus-associated ribosomal set is therefore larger than 68; on the tracked ortholog table the cytoplasmic set including RPLP/RPSA/FAU/RACK1/UBA52 is 71 genes, and adding mitochondrial ribosomal genes brings the ribosomal-related total to ~144. The Layer-1 conclusion does not change under any of these definitions — the deposited 68-gene exclusion already leaves obs/null = 0.501, and the broader housekeeping exclusion (1,158 genes) leaves 0.479. An earlier internal count of 79 corrected ribosomal genes is not reproduced from the tracked ortholog table: the strict regex gives 68 and a cytoplasmic-inclusive definition gives 71. The Layer-1 conclusion is invariant across all of these definitions, so no single corrected count is relied upon here.

Marker-classification scope. Within-type rank-1 CPC1 drivers are scored as canonical identity markers by membership in a fixed list of basal-ganglia lineage markers, applied globally — a driver counts whenever its symbol is in the list, with no check that the marker is appropriate to the type it drives. Because the list is region-specific, the rule is informative only where the panel matches the tissue: on the basal-ganglia atlas the fractions (18/55, 7/52, 5/52; Fig 2C) index proximity to identity structure, whereas on whole-body types most types have no eligible marker in a basal-ganglia panel at all, so a marker fraction there is bounded low by panel mismatch rather than biology and is not commensurable with the basal-ganglia fractions — the reason the human–mouse marker fraction is not reported in the main text. These fractions are a coarse index rather than a validated per-type marker call; no per-type marker verification was performed, and the classifier's imprecision affects the exact fractions but not the qualitative conclusion that a canonical marker tops the standardized axis for a minority of types.

Macaca pooling sensitivity (primate replication). The macaque arm of the basal-ganglia atlas is a genus-level pool, following the source atlas's own grouping: six Macaca mulatta donors (382,079 nuclei) and two Macaca nemestrina donors (166,202 nuclei, 30.3% of macaque cells), assigned by NCBI taxon identifier in the atlas's donor table rather than by the donor-prefix rule, which does not separate them. Because Layer 2 measures within-type covariance orientation, a pooled arm places a between-species component inside the measured quantity, and the label-shuffle null cannot remove a component that varies across types. Restricting the macaque arm to the six Macaca mulatta donors and recomputing both affected pairs from the cells, refitting the joint-PCA basis, the centroid-optimal rotation and the per-type covariances on the restricted donor set, reproduces the result: post-rotation subspace similarity remains below pre-rotation and above its permutation null at k = 1, 3 and 5 under both weightings in both pairs, with every permutation p at the 10⁻⁴ floor, and the compression is marginally stronger under restriction in eleven of twelve comparisons. Three differences travel with the restricted run and prevent a direct comparison of the statistics themselves: the arm has six donors rather than eight, the retained subspace dimension under standardization falls by one in each pair, and one sparsely sampled dopaminergic type falls below the 100-cell inclusion threshold, leaving 54 and 51 matched types. The canonical identity-marker fractions rise under restriction, to 25 of 54 and 8 of 51, so the pooled fractions reported in the main text understate. Layer 1 is nearly unmoved (obs/null 0.360 pooled against 0.361 restricted, the retained dimension unchanged at 37, the same type most divergent, ranking Spearman 0.883).

5. Pseudo-bulk centroid robustness

The primary centroids are the mean of per-cell log1p(CP10K) expression. Because the mean of log-transformed counts can be sensitive to per-cell sparsity and depth, we recomputed the configuration under two pseudo-bulk alternatives that aggregate before log-transforming: an equal-cell-weighted profile (mean of per-cell CP10K per type, then log1p) and a library-size-weighted aggregate (summed raw counts per type, normalized to CP10K, then log1p). Both were built from the same aligned, subsampled cells that produced the primary centroids (a rebuild of the primary mean-of-log centroids from these raw counts reproduces the deposited obs/null to within 10⁻⁷). The configuration remains conserved under both: global obs/null 0.487 (equal-weighted) and 0.620 (library-size-weighted), with lineage-stratified obs/null 0.650 and 0.799 respectively (each p < 10⁻⁴, 10,000-permutation null). Procrustes distances are not comparable across the three constructions because the number of components retained at 95% variance differs (33, 36, and 45); the obs/null ratios, each computed against the permutation null in its own space, are the comparable quantity. The conserved configuration is therefore not an artifact of the mean-of-log centroid construction.

6. Replication inventory and diagnostics

The configuration result was tested across six independent cross-atlas attempts plus one pooled-heterogeneity attempt; the permutation procedure was identical throughout (label-shuffle null, 10,000 iterations, seed 42).

- Sun et al. 2023 mouse atlas (10x 3' v3, nine tissues): obs/null = 0.554, p < 10⁻⁴, n = 15. A tissue-matched variant (lung endothelial cells from lung only) gives 0.490, p < 10⁻⁴.
- PanSci single-nucleus (EasySci combinatorial indexing, technology independent of both 10x datasets): obs/null = 0.552, p < 10⁻⁴, n = 16.
- CellHint human harmonized meta-atlas (2.87M cells, nine tissues, human side varied): obs/null = 0.448, p < 10⁻⁴, n = 15.
- Pan-Census pooled replication (15 CZ CELLxGENE Census datasets across 15 collections, sharing neither original atlas): obs/null = 0.811, p < 10⁻⁴, n = 22. Reported separately because its heterogeneity-pooled effect size is not comparable to the single-source replications.
- Andrews et al. liver atlas (single tissue): obs/null = 0.797, p = 0.116, n = 6 — a non-replication attributable to reduced power (n = 6) and single-tissue scope; the effect size is comparable to the successful replications (Procrustes scale s = 0.229, in the compressed range).
- MCA x HCA (aggregated microwell-seq mouse x human): obs/null = 1.003, p = 0.542, n = 17 — a non-replication attributable to microwell-seq low sensitivity in MCA (~500–1,000 genes/cell; scale s = 0.267 vs 0.902 primary).

Within-human localization diagnostic. To localize the MCA x HCA failure, HCA human centroids were compared to Tabula Sapiens human centroids on a 6-type subset: obs/null = 0.728, p = 0.003, n = 6. Human centroid geometry is consistent across independent atlases, placing the failure in MCA rather than in the framework (S2 Fig).

Cross-atlas ranking non-replication. The per-type divergence ranking does not replicate across atlases in any tested case (cross-atlas Spearman ρ = +0.15 Sun2023; +0.19 PanSci; −0.05 pan-Census; −0.14 CellHint at matched 15-type baseline, declining to −0.04 under full ontology/tissue harmonization; S4 Table). Their signed mean is +0.04 and their median +0.05; substituting the fully harmonized CellHint value gives a mean of +0.06. The four are not mutually independent, since each replaces only one arm of the primary comparison, so shared-arm errors are positively correlated across them. The apparent unharmonized CellHint ρ = −0.39 is an artifact of comparing residuals across incompatible PCA subspaces, resolved by same-dimension recomputation (S3 Table).

Matched-n baselines for the replication panel. Because the null median varies with type count, a replication's obs/null cannot be read against the primary's 0.522 at 35 types. Restricting the primary to each replication's own matched types and re-running the identical pipeline gives each bar its own baseline: 0.436 (Sun2023, n = 15), 0.445 (PanSci, 16), 0.430 (CellHint, 15), 0.429 (pan-Census, 22), 0.323 (Andrews, 6) and 0.543 (MCA x HCA, 17). The three single-source replications sit 0.017 to 0.118 above their baselines; the pooled replication and the two non-replications sit 0.383 to 0.474 above theirs. The retained component count is fitted at 95% variance and falls with n (33 at 35 types down to 7 at 6), which is a further reason these are read within a bar rather than across bars. Two further points bear on how the baselines themselves should be read. The primary's own ratio rises with type count, from a median 0.464 over random 6-type subsets to 0.522 at 35, so part of any gradient across bars is n rather than data provenance; and each replication's matched types are, in five of six cases, more conserved in the primary than the types it misses, which places the matched baselines below random type sets of the same size. The two effects agree in sign for all six replications, including the one whose matched types are less conserved (exact binomial p = 0.016), so the deficit is a property of which types a replication happens to match rather than an artifact of the baseline construction.

7. Macaque extension (single-source design)

CellWarp was applied to a human–macaque comparison using cynomolgus centroids from a single source, Qu et al. (GEO GSE196792), with fully symmetric raw-count preprocessing (an earlier RIRA + Qu combination used asymmetric preprocessing and is deprecated). A three-way human–mouse–macaque ortholog intersection gave 13,927 genes (82.1% of the human–mouse space), and 12 cell types matched between Tabula Sapiens and Qu. Macaque cells were processed from raw 10x UMI counts (normalize_total 1e4 then log1p; up to 2,000 cells/type, seed 42). The macaque hepatocyte was defined by organ-partitioning Qu's "Epithelial cell" annotation (Organ = Liver) without marker re-annotation, so it may include non-hepatocyte epithelial cells — a definitional caveat on the hepatocyte reversal.

Result. Procrustes coherence was detected (obs/null = 0.810, raw p = 0.0043, n = 12, 10,000 permutations) but does not clear multiple-testing correction (Bonferroni p ≈ 0.22 across the k = 52 inferential family; not significant). It is reported as directionally consistent, not separately confirmatory, and obs/null magnitudes are not interpreted across species pairs (they are confounded by atlas and tissue composition; the macaque/mouse ordering inverts at matched granularity). A matched-n human–mouse control on the same 12-type subset is stronger (obs/null = 0.440). Excluding the five immune types (whose cross-atlas tissue composition differs most) leaves obs/null = 0.733, p = 0.013 on 7 non-immune types (matched-n human–mouse control 0.485), so composition asymmetry accounts for part but not all of the gap. The per-type ranking does not replicate between the two pairs (Spearman ρ = 0.147, p = 0.649); hepatocyte reverses from most-conserved (rank 12/12) to most-flexible (rank 1/12), an instance of the general cross-atlas ranking instability (hepatocyte is also rank-volatile in the Sun2023 and CellHint replications).

8. Ten mechanistic null tests for the per-type ranking

Ten pre-specified mechanistic hypotheses for the per-type divergence signal were tested against the 35-type per-type residual; none reached significance (all Spearman ρ against the residual unless noted). Power to detect a moderate effect (ρ ≈ 0.30) is ~37% at n = 35, so the tests rule out strong but not moderate associations. (1) Housekeeping-gene ratio, ρ = 0.167, NS. (2) TF network complexity (DoRothEA), ρ = −0.229, NS. (3) Niche-adaptation gene sets (MSigDB), 0/6 significant after FDR. (4) Within-type expression variance, ρ = −0.038, NS. (5) Inter-donor variance, ρ = −0.127, NS. (6) Expression-level confounds, all |ρ| < 0.21, NS (11 sub-tests). (7) PPI network centrality (STRING v12), best ρ = 0.291, 0/27 metrics significant after FDR. (8) Promoter phastCons conservation (UCSC 20-way), ρ = −0.058, NS. (9) H3K27ac enhancer conservation (ENCODE), ρ = −0.429, n = 6, NS. (10) Drug-target conservation (ChEMBL/DrugBank), ρ = −0.176, n = 34, NS. Design status: nulls 1–6 pre-specified as confound diagnostics; 7–9 designed sequentially with ρ < 0.35 closure thresholds locked before invocation; 10 exploratory. A drug-target-density baseline (ρ = −0.323, p = 0.059) was likewise non-significant.

Two additional preregistered but unreported analyses used the per-type residual as an input and are catalogued in SCOPE.md rather than reported here: an aging-axis plan (within-mouse aging direction; not executed) and a hepatocyte-rigidity/drug-induced-liver-injury landmark test (executed; null under its own pre-specified covariate-falsification gate). Neither is among the ten mechanistic nulls, and neither tests age-composition as a confound on the cross-species residual (that confound is disclosed as acknowledged-but-untested in the main text).

9. Donor-split within-species control

To separate cross-species divergence from within-species individual variation under matched protocol, the 24 Tabula Sapiens donors were partitioned into two non-overlapping halves over 100 random balanced splits (seed 42). This human-only partition is a different construction from the two-species donor split used for the conservation score in section 12, which partitions both species' donors independently under its own seed sequence; the two are not interchangeable and the shared phrase "100 splits" refers to different objects. For each split, within-species Procrustes (human half 1 vs human half 2) and cross-species Procrustes (human half 1 vs mouse) were computed in a shared PCA space (median 32 components; 31 types median, feasible types requiring ≥100 cells in both halves). The coherence hierarchy fell as expected: self-comparison 0.033 < within-species donor-split 0.375 (95% CI 0.318–0.423) < cross-species 0.527 (95% CI 0.485–0.584) < null 1.0. Cross-species exceeded within-species in 100/100 splits (median delta = +0.159, 95% CI +0.100–+0.218). The contrast is cross-(atlas and species) versus within-(atlas and individual), not protocol-matched, because the cross arm spans two atlases; the 100/100 figure is direction-robustness across non-independent resamples of a single 24-donor atlas (5 of 24 donors contribute ~73% of cells), not independent replication, and likely biases the delta upward. An independent-PCA-per-comparison sensitivity gives delta = +0.158 (vs +0.159). A matched-scale 6-type cross-atlas variant (S4 Fig) reverses the hierarchy (within-species 0.607 vs cross-species 0.317), showing that unmatched protocol between independently constructed atlases dominates the within-species arm — which is why the within-atlas donor split, not a cross-atlas within-species comparison, is the valid test.

10. Selection/derangement circularity control

Results §5 restricts the configuration to the top quartile of the per-gene conservation score C, where obs/null = 0.384 against 0.709 for the divergent quartile and 0.525 ± 0.012 for expression-matched random sets. Because C is estimated on the same 35 centroids that produce the geometry, part of that advantage could be selection on noise rather than signal. Three distinct objections follow, and they need different instruments.

Selecting on C. A correspondence-derangement null was run first, with acceptance thresholds fixed before execution: per draw, derange the 35 mouse centroid rows, recompute C, re-select the top quartile, and re-run the unmodified pipeline. The real value sits far below it (derangement 0.991 ± 0.021, 1st percentile 0.927, z = −29.5, 0 of 1,000 draws at or below the real value; label-shuffle cross-check 0.983 ± 0.024, z = −25.3). This control is reported here because it was pre-specified, but it does not answer the objection. Deranging the correspondence collapses the selection threshold (Q75 of C falls from 0.59 to 0.08), so the null sits at chance because there is no correspondence to select on, and any gene set evaluated under the true correspondence clears it: the full unselected 16,959-gene space also passes, at 0.522 and z = −22.8. What the control establishes is that a cross-species correspondence exists, which Fig 1B established directly.

The objection is answered instead out of sample. Partitioning the donors of both species into halves, C was computed on one half, the top quartile selected on that half alone, and the configuration evaluated on the other half, so selection and evaluation share no donor. Across twenty splits in both directions, the out-of-sample selected set outperforms the full unselected gene space in all forty comparisons (margin median 0.121, minimum 0.092) and falls below all one hundred expression-matched random sets drawn on the evaluation half (z = −8.9 and −12.4). Comparing the out-of-sample selection against selection performed on the evaluation half itself, which carries the full winner's curse, the out-of-sample set retains a median 90% of the advantage (interquartile range 79% to 99%). The same quantity measured on C rather than on the geometry agrees: genes selected on one half have mean C of 0.663 on the other, against 0.730 for genes selected on the evaluation half and 0.318 for all genes, so roughly 84% of the apparent gain survives. Because the evaluation halves carry half the donors, none of these ratios is comparable to the published 0.384 or 0.525; the comparison that carries the result is between arms within a split.

Ontology and ortholog pre-selection. This is a separate objection and the derangement null does not touch it. The ortholog half is a scope condition rather than a controlled variable: because the permutation null is computed in the same gene space as the observed statistic, any influence of the 1:1 restriction raises both together and divides out, so this design can neither create the effect nor detect it. The reported magnitude is a property of the 1:1 ortholog space, which excludes lineage-specific expansions and species-specific families. The ontology half is addressed by the marker-similarity-stratified null of section 2, which permutes labels only within groups of transcriptionally similar types: the signal erodes monotonically as those groups are made finer and no longer clears p = 0.05 at fifteen groups, so most of the unrestricted result is attributable to coarse marker structure, with a residual persisting to fourteen.

Annotation-derived structure in C itself. C is the cross-species agreement of a gene's expression profile across centroids whose labels were assigned, in both atlases, by marker-based annotation. Genes in a type's canonical program therefore score high partly by construction, and neither the derangement null nor the expression- and specificity-matched nulls address this. Two measurements bound it. A full human transcription-factor census shows no enrichment against the expression-matched background, so the effect is not a general property of regulators; and canonical non-transcription-factor markers of the same types sit at the jointly matched null, so it is not a general property of annotation markers either. What remains is specific to the curated list of lineage-defining regulators for these 35 types, and that list was assembled against those same types. We state this as a scope condition: the enrichment quantifies the identity interpretation of the conserved set for the cell types under study, and is not evidence about regulation in general.

Taken together, the selection objection is answered out of sample, the ortholog objection is a scope condition that no design here can separate, and the ontology and annotation objections are bounded but not eliminated. This section does not bear on the Layer-2 covariance analysis. (analysis/selection_null/)

11. Bootstrap and leave-one-out cross-validation

Bootstrap robustness (global). 100 iterations at 50% cell subsampling per type per species; per-iteration significance by 1,000-permutation null. Procrustes-distance coefficient of variation = 0.004 (mean 61.18, SD 0.24), ~50x below the pre-specified CV = 0.2 gate; 100/100 iterations significant at α = 0.01; PCA component count stable at 33 across all iterations. The permutation null was not recomputed per iteration, so this bounds the observed Procrustes distance and not the observed-to-null ratio; the deposited artifacts record per-iteration distances but not per-iteration null medians, so no interval on the reported effect size is recoverable from them.

Bootstrap ranking stability. 1,000 iterations resampling cells with replacement within type, refitting PCA and Procrustes per iteration. All 35 types classified stable (95% CI width ≤ 10; median width 3, maximum 7). The within-atlas / cross-atlas inversion: bootstrap CI width vs mean cross-atlas rank shift correlated at Spearman ρ = −0.410 (p = 0.073, n = 20) — types most precisely ranked within an atlas shift most across atlases (Fig 4B; S3 Fig).

Leave-one-out cross-validation. Per fold, PCA (95% threshold, 32–33 components) and rotation refit on the 68 training centroids only; the held-out type projected into the training subspace and its human position predicted by the training rotation applied to its mouse centroid; error-to-null ratio = predicted-position error / mean distance to the 34 training human centroids. All 35 types predicted better than chance (35/35 ratios < 1.0; mean 0.4201). Best: CD8+ T cell (0.226); hardest: hematopoietic stem cell (0.796). By lineage: immune 0.39, structural 0.39, epithelial 0.45, stem/progenitor 0.52 (a trend, given the progenitor Smart-seq2 protocol confound).

12. Per-gene conservation score C and master-TF enrichment

For each ortholog, C is the Pearson correlation of the gene's expression profile across the 35 matched centroids in human versus mouse, computed directly on centroids (mean-centered, scale-invariant, so it measures conservation of the cell-type-specificity pattern, not magnitude), independent of the joint-PCA/Procrustes axes (Spearman ρ = 0.27 with the within-data axis-loading metric, confirming non-circularity). 15,940 of 16,959 orthologs have a defined C. C varies continuously (Hartigan dip p = 2.8e-5 but D = 0.007, a broad continuum), and is reported as a ranked quantity, not a thresholded set (top-quartile Jaccard across donor splits = 0.58).

Enrichment against matched nulls. Conserved-set properties are evaluated only against matched backgrounds. The expression-matched null uses 20 equal-frequency mean-expression bins; the joint null uses 100 bins (10 expression x 10 Tau-specificity). A pre-specified list of 73 canonical lineage-defining (master) regulators, mapped to the 35 matched lineages and all present in the ortholog space with a defined C, has median conservation percentile 0.94 versus 0.54 (expression-matched) and 0.76 (joint expression-and-specificity-matched); both p < 10⁻⁶ (10⁶ matched draws; zero draws reached the observed median). The residual gap 0.76 -> 0.94 is specific to this curated set and does not generalize to transcription factors as a class. Scored the same way against the same backgrounds, a full human transcription-factor census (Lambert et al. 2018; 1,217 of its genes fall in the ortholog space with a defined C) has median conservation percentile 0.53, indistinguishable from the expression-matched null and below the jointly matched one; canonical non-transcription-factor markers of these cell types sit at the jointly matched null. Being a transcription factor is therefore not what places a gene high in C. The 73 are a fixed list specified in the analysis plan and mapped to the same 35 matched lineages that define C, so their enrichment is not separable by these nulls from the fact that they were selected against those lineages; adding omitted masters (ATOH1, ZBTB16/PLZF) as a post-hoc sensitivity leaves the median at 0.94. We therefore read this as a quantification of the identity interpretation rather than a discovery about regulation.

Geometry attribution. The obs/null pipeline was rebuilt on the conserved-C quartile (3,985 genes), the divergent-C quartile, and 20 expression-matched-random sets. The conserved set gives obs/null = 0.384, far below the divergent set (0.709) and the expression-matched-random mean (0.525 ± 0.012), placing it >11 SD below the matched-random mean. As pre-specified, the conserved set's absolute value is partly expected from selection; the interpretable contrasts (conserved vs divergent; conserved vs expression-matched-random) both favor the conserved set. Reproducibility: per-gene C agrees across 100 donor splits (median Spearman ρ = 0.80, vs a 0.94 cell-sampling ceiling and 0.015 gene-shuffle null); this split partitions both species' donors and is a different construction from the human-only 100-split partition of section 9, which shares the phrase but not the object; the master-TF enrichment recovers in all 200 halves and in each protocol (10x and Smart-seq2 percentiles both 0.91). A fresh CZ CELLxGENE Census re-acquisition recovers the headline (obs/null 0.521 vs 0.522) and C at Spearman ρ = 0.989. Per-gene C attenuates across the protocol switch (cross-protocol ρ = 0.59 vs 0.80 across donors), so a cross-dataset per-gene replication is the most informative next experiment for the per-gene claim; the master-TF result itself is protocol-invariant. This module was pre-specified with its own matched-null thresholds and is evaluated outside the k = 52 Bonferroni family. (analysis/conserved_contribution/)

13. Software environment and reproducibility

All analyses ran in Python 3.12 in a pip-managed virtual environment; the version-pinned manifest is archived as requirements.txt and enumerated in S12 Table, and a global seed of 42 was set at every stochastic entry point, giving deterministic results from the archived data and code. Primary datasets (Tabula Sapiens, Tabula Muris Senis, CellHint) were accessed via CZ CELLxGENE Census (version 2025-11-08), the reproducibility anchor for those datasets; Tabula Microcebus via CZ CELLxGENE Discover (download date anchor). Human–mouse 1:1 orthologs are from Ensembl BioMart release 115 (GRCh38.p14 / GRCm39; accessed 2026-03-12), archived as a CSV that anchors all gene-space definitions; human–macaque and human–mouse-lemur orthologs from the same release. The Procrustes implementation was verified against scipy.spatial.procrustes to machine precision. The full classification of every script, analysis directory, output directory, and dated pre-specification (paper / banked / other-project / exploratory) is provided as SCOPE.md.
