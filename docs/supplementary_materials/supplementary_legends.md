# Supplementary Legends (Retired)

The authoritative supplementary figure and table legends are the legend
blocks embedded in `docs/submission/manuscript_combined.txt` (main-text
section 14), from which `supplementary_materials.pdf` is generated by
`scripts/assemble_supplementary_pdf.py`.

This standalone legends file has been retired to remove a duplicate that
could drift out of sync with the manuscript. Its last full version is in
this repository's git history. Do not re-add legend text here; edit the
manuscript source instead.
